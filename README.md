# Portfolio

Personlig portfolio-hemsida byggd med vanlig HTML, CSS och JavaScript (inga ramverk).

## Struktur

```
index.html      Startsidan – öppna den i webbläsaren
css/style.css   Stilar: reset och variabler för färger, typsnitt, avstånd
js/main.js      JavaScript
images/         Bilder
assets/         Övriga filer (typsnitt, ikoner, dokument)
```

## Köra projektet

Dubbelklicka på `index.html`.
